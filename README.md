# Module End Assignment - MySQL

## E-Commerce Customer Churn Analysis

### About the Assignment

This assignment focuses on **E-Commerce Customer Churn Analysis using MySQL**.

The purpose of the project is to analyze customer data and understand **customer churn and customer behavior**. Churn means when a customer stops using or purchasing from an e-commerce service.

The dataset contains customer information such as tenure, app usage, preferred payment method, order category, cashback amount, days since last order, and other customer details.

The assignment involves creating the database and table, working with the customer data, checking the data, and writing SQL queries to answer different business-related questions.

### Concepts Used

* DDL and DML
* SELECT and WHERE
* ORDER BY
* Aggregate Functions
* GROUP BY and HAVING
* NULL Handling
* CASE
* Joins
* Subqueries
